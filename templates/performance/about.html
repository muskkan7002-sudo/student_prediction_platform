Project Overview

About The Project

Student Performance Prediction System is a practical industrial training project built with Django and Machine Learning. It helps institutions identify academic performance levels and gives useful improvement guidance for students.

IN

Inputs

Attendance, study hours, previous marks, assignment score, and sleep hours.

OP

Output

A performance category, readiness score, practical recommendation, and saved record.

AI

Technology

Python, Django, SQLite, scikit-learn, pandas, joblib, HTML, and CSS.

ML

Model Evaluation

Decision Tree, Random Forest, Logistic Regression, KNN, and Naive Bayes are compared.

DB

Dashboard

Saved prediction records are summarized with category counts and average indicators.

CM

Metrics

The training script generates accuracy, precision, recall, F1-score, and confusion matrix.

1 Student details are entered through the Django form.
2 The values are sent to the prediction function.
3 The best trained model returns a performance category and readiness score.
4 The dashboard displays records, trends, and model evaluation metrics.
